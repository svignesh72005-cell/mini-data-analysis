# 📊 Mini Data Analysis Project

## 📌 Project Overview
This project performs basic data analysis on a sales dataset using Python.  
It includes data cleaning, summary statistics, category-wise analysis, visualization, and Excel export.

---

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- openpyxl

---

## 📂 Project Files
- `sales_data.csv` – Raw sales dataset
- `analysis.py` – Main Python analysis script
- `sales_bar_chart.png` – Generated bar chart visualization
- `cleaned_sales_data.xlsx` – Cleaned dataset exported to Excel

---

## 🔍 Features
- Displays first 5 rows of dataset
- Shows dataset information
- Checks missing values
- Cleans data
- Generates summary statistics
- Calculates total and average sales
- Performs category-wise sales analysis
- Creates bar chart visualization
- Exports cleaned data to Excel file
